## Research Software

- **FastMurphi** — Murphi-based model checker with heuristic search. [github.com/yongjianli-group/FastMurphi](https://github.com/yongjianli-group/FastMurphi)
- **MurphiLLM** — Murphi + LLM (LangChain) for protocol verification. [github.com/yongjianli-group/MurphiLLM](https://github.com/yongjianli-group/MurphiLLM)
- **ChiselFV / ChiselFV2** — source-level formal verification for Chisel (symbolic execution, BMC, JasperGold). [github.com/chenty2002/ChiselFV2](https://github.com/chenty2002/ChiselFV2)
- **CoupledL2 Verification** — model checking of industrial-scale XiangShan RISC-V L2 cache (TileLink) in Chisel.
- **wiseParaverifier** — induction-based verifier for parameterized protocols. [github.com/xiuqiqiq/WiseParaVerifier](https://github.com/xiuqiqiq/WiseParaVerifier.git)
- **paraVerifier** — automatic parameterized cache-coherence verification with Isabelle proofs. [github.com/paraVerifier/paraVerifier](https://github.com/paraVerifier/paraVerifier)
